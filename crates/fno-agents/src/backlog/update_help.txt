Usage: fno-py backlog update [OPTIONS] TASK_ID

Arguments:
  TASK_ID  Feature ID (ab-XXXXXXXX)  [required]

Options:
  --locked-by TEXT                Lock owner id ('null' to release)
  --locked-by-harness TEXT        Holder's harness/provider
                                  (claude|codex|gemini). 'null' clears.
  --locked-by-harness-session TEXT
                                  Holder's harness session UUID. 'null'
                                  clears.
  --has-brief TEXT                Set has_brief flag
  --plan-path TEXT                Plan directory path. 'null' clears.
  --pr-number TEXT                PR number. 'null' clears.
  --pr-url TEXT                   PR URL. 'null' clears.
  --repo TEXT                     owner/name of the repo the PR lives in, when
                                  that differs from the cwd checkout; naming
                                  it makes the stamp an assertion.
  -p, --priority TEXT             New priority
  --blocks-everything             Acknowledge that p0 blocks all downstream
                                  work.
  -t, --title TEXT                Update display title
  -d, --details, --description TEXT
                                  Update free-form details/rationale (stored
                                  in `details`). Pass 'null' to clear.
  --details-file PATH             Read --details from a file ('-' = stdin)
                                  instead of the flag.
  --domain TEXT                   Update domain (e.g. code)
  --size TEXT                     Update size estimate: S|M|L
  --difficulty TEXT               Intrinsic work difficulty: low|medium|high.
                                  Not a model or capacity hint.
  --model TEXT                    Pin the model dispatchers launch this node's
                                  worker on (), e.g. fable|opus|sonnet or a
                                  full provider-model id. Single non-
                                  whitespace token. Pass 'null' to clear
                                  (revert to provider default).
  --batch TEXT                    Set the batch id this node is a member of
                                  (marks node.batch, batch-lane Wave 2). Pass
                                  'null' to clear (requeue for individual ship
                                  on abandon).
  --orphan-ok TEXT                Record why this node deliberately serves no
                                  mission, exempting it from the orphan
                                  metric, the board flag, and the ordering
                                  tiebreaker. Pass 'null' to clear.
  --dispatch-verb TEXT            Verb a dispatcher launches this node with
                                  (US3), e.g. /think. Refused at write when it
                                  is not one bare verb word; the
                                  config.dispatch allowlist still applies at
                                  dispatch. Pass 'null' to clear (revert to
                                  the /target --no-merge default).
  --dispatch-brief TEXT           Free-text brief carried to the worker via
                                  TARGET_BRIEF env at cold-start (US3), never
                                  the command line. Warns at write and is
                                  refused at dispatch when over the 8 KB env
                                  budget. Pass 'null' to clear.
  --type TEXT                     Update node type (feature|epic|bug)
  --public / --no-public          Mark node for the public roadmap (fno
                                  backlog roadmap)
  --project TEXT                  Reproject this node (use for migrating
                                  wrong-scope nodes)
  -c, --cwd TEXT                  Update cwd (pair with --project for
                                  migration)
  --source-node TEXT              Origin node this node came out of (id, slug,
                                  or hex). 'null' clears; a self-reference or
                                  an unresolved id refuses.
  --related TEXT                  Replace the related list (asserted,
                                  symmetric, non-blocking); repeat or comma-
                                  separate. 'null' clears.
  --blocked-by TEXT               Replace blocked_by list
  --add-blocker TEXT              Append blocker IDs
  --remove-blocker TEXT           Remove blocker IDs
  --acknowledge-collisions TEXT   Comma-separated ab-IDs of collisions
                                  deliberately accepted. Pass
                                  '__skipped_check__' to record a skipped
                                  check.
  --parent TEXT                   Set parent node ID. Pass 'null' to clear
                                  (de-orphan to top-level). Validates target
                                  exists and rejects cycles. Moving a
                                  contained node away from its owner un-
                                  contains it.
  --completion-note TEXT          Append free-text completion note. Multiple
                                  calls append with ' + ' separator.
                                  Whitespace-only is a no-op. Pass 'null' to
                                  clear.
  --add-pr INTEGER                Append a follow-up PR number to
                                  additional_prs. Pair with --add-pr-url /
                                  --add-pr-note for context. Re-adding an
                                  existing number updates that entry in place.
  --add-pr-url TEXT               URL for the --add-pr entry (optional).
  --add-pr-note TEXT              One-line note for the --add-pr entry
                                  (optional).
  --remove-pr INTEGER             Remove a PR entry from additional_prs by
                                  number. No-op if absent. The primary
                                  pr_number is unaffected (use --pr-number to
                                  change that).
  --caused-by TEXT                Node id this node was created to address
                                  (causal link, W4). Pass 'null' to clear.
  --fixes-pr INTEGER              PR number this node fixes (causal link, W4).
                                  Pass 0 to clear.
  --reverted / --no-reverted      Mark this node's ship as reverted (manual
                                  fallback for reconcile's best-effort revert
                                  detection).
  -F, --force                     Escape the one-plan-one-node refusal on
                                  --plan-path: bind this node to a plan
                                  another node already owns (a deliberate
                                  repoint). The other holder is still named on
                                  stderr.
  --help                          Show this message and exit.

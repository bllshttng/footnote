# door_type

The change touches a CLI flag, config key, schema, shipped file name, or a skill or agent name. These are one-way doors: renaming them later costs every user who already typed them.

Treat a one-way door as a promise. Put its evidence first: the receipt, the exit code, or the check that proves the door does what the plan says.

# blast_radius

A changed file has callers outside the plan, or a CI gate binds it. List the tests, docs, gates, and callers under the change, and name who breaks if it goes wrong.

The gates reshape the work more than the design does. Measure the headroom now, so the worker does not learn it from a red check.

Feeds: Binding constraints

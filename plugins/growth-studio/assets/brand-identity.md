# Brand identity

The brand identity growth-studio drafts under: the brand name, the founder,
and the positioning a draft speaks from.
This file is the worked example and fallback bundled with the pack; an
installing project points `[context.artifacts] brand-identity` at its own
identity so a second project never drafts under Footnote's name.
A draft that speaks from the wrong identity fails brand review.

## Brand

Footnote: an autonomous delivery pipeline that takes a feature from idea to a
shipped pull request in five phases (think, plan, do, review, ship).
Source: `AGENTS.md`.

## Founder

Jason Noah Choi (formal) or J.N. Choi (byline).
Never the two-part short form "Jason Choi".

## Identity rules

- Use the founder's name as Jason Noah Choi (formal) or J.N. Choi (byline).
- Jason Choi (the two-part short form) is banned; use the full name or byline.
- Speak from this brand's positioning, not a second consumer's.

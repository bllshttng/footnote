# scripts/ci/reachable-paths-baseline.txt - the reachable-paths ratchet.
#
# Held by scripts/ci/check-reachable-paths.sh. A line here is a KNOWN twin,
# duplication, or registry offender, with its carrier set and a reason. The
# gate fails on:
#   - a NEW finding not listed here (single-source it, or add a line + reason),
#   - CARRIER-SET drift on an A/B line (a twin copied into one more file, or a
#     carrier removed - update the meta in the same PR),
#   - a STALE line (one side changed alone, or an offender was fixed - update
#     the sibling or delete the line in the same PR that changed it).
#
# Engine A classes:
#   protocol  cross-process contract (event kind, config key, envelope tag,
#             argv flag). Twin BY DESIGN: both sides must agree forever, and
#             the stale check is what now guards that agreement.
#   msg-twin  the same user-facing message maintained in .py and .rs. Sync
#             guarded until single-sourced (campaign node owns the collapse).
#   data      inert constant (path, filename, URL).

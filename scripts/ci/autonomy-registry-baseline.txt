# Known spawn-shaped call sites, held by the CI ratchet (x-aaaf wave 3.3).
# Each entry is <file>::<enclosing-function> (Python) or <file>:: (shell,
# file-level: bash has no reliable function-boundary AST, so a shell site is
# tracked per-file, not per-function - the ceiling this baseline accepts;
# a Python site is keyed on function, not line, so a reorder inside an
# existing caller does not trip the gate).
#
# A NEW site appearing anywhere the check scans is what trips CI. Every line
# below is either an autonomy-status spawner name (matches a row in
# `fno autonomy status`) or an explicit reason the site is NOT autonomous
# (an operator-invoked command, or plain text/comment with no real call).
#
# Forgetting a gate is refused at runtime by config.autonomy.enabled.
# Forgetting to REGISTER a new spawner is refused here, at CI.

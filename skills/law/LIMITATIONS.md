# Law limitations

## Known Limitations and Deferred Work

- **Invocation is the authority, and invocation is forgeable.** A one-step `/fno:law` can be minted by anything that can put user-shaped text into this session, which includes `fno agents mail send --raw`. The operator ruled for one step on 2026-08-29 with that named (ruling d-e1eec854). This is the trade, written down rather than discovered later.
- **The forgery is not detectable here, and that was measured, not assumed.** Across every transcript under this machine's claude project directory, 2173 user turns carrying an `<fno_mail>` envelope are recorded with `promptSource: "typed"`, and 2439 with `origin: {"kind": "human"}`. Both harness-supplied fields report human and typed on an injected turn. `--raw` strips the `<fno_mail>` envelope, which is the only remaining marker. So there is no field to refuse on. A refusal built on one of those would be theater.
- **What the retired ceremony actually bought.** The staged proposal, the 64-character content hash and the one-shot permission receipt refused a bypass-mode or headless session. They did not refuse an attended chat, which approved the prompt without reading the hash, and mail lands as an attended chat. The ceremony blocked the honest path and was waved through on the dishonest one, so retiring it gave up less than its four steps cost.
- **Attribution survives the trade.** A chat recording carries `authority_source: chat_attested` and never `operator`. That value reads in the **law** lane at or after `AUTHORITY_LANE_CUTOVER`, and it stays distinct from `operator`, so a reader can always tell a chat recording from a person at a terminal. A chat recording still cannot prove a human origin, and it no longer claims to.
- **A caller that nothing marks is still refused.** No harness session and no terminal means no decider, and `fno inbox law set` exits 3 without recording. Law is not inherited by silence.
- **Recording law from chat works. Retracting it does not.** On a law-lane row, `retract_decision` requires `authority_source` to be exactly `operator`, so a chat-recorded law needs an attended terminal to withdraw. Supersession is not affected and accepts `chat_attested`.
- **The store is machine-local.** A rule a stranger cloning the repository must obey does not reach them from here.

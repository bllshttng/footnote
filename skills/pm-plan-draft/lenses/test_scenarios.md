# test_scenarios

For each observable behavior change, give the plan a happy path, an error path, and one edge case. A behavior with only a happy path is a demo, not a feature.

Write the error path before the code exists: it names what the caller sees, not what the function returns.

Feeds: Acceptance Criteria (HP, ERR, EDGE)

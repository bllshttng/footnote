# blast_radius

A changed file has callers outside the plan, or a CI gate binds it. If it goes wrong, name who breaks. List the tests, docs, gates, and callers under the change.

The gates reshape the work more than the design does. Measure the headroom now, so the worker does not learn it from a red check.

Feeds: Binding constraints
Source: strategic-partner cognitive-patterns, Scope Iceberg and Blast Radius (MIT, see NOTICE)

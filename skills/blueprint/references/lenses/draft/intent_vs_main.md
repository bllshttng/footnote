# intent_vs_main

The node claims something is missing, broken, or already added. Compare each claim with what main does, at the line, before you design anything.

Four claimed additions can already be shipped. Every verdict gets a form: `exists at <file:line>`, `exists as <other name> at <file:line>`, or `absent after <exact command>`.

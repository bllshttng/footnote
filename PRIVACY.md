# Privacy

Footnote is an open-source workflow plugin. It stores project state, agent
transcripts, and configuration on the user's machine. When a user invokes an
AI provider through Footnote, prompts and selected project context are sent to
that provider under the user's provider account and terms. Footnote does not
operate a hosted service or collect plugin analytics.

Users control local state and can remove it from their machine. Source code and
support requests are handled through the public GitHub repository.

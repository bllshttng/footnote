# Privacy

Footnote is an open-source workflow plugin. It stores project state, agent transcripts, and configuration on the user's machine. User prompts and selected project context go to the AI provider they invoke under that provider's terms. Footnote runs locally and does not operate a hosted service or collect analytics for its maintainers.

Users control local state and can remove it from their machine. Source code and support requests are handled through the public GitHub repository.
